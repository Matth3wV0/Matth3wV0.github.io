Capabilities

Built for Speed. Hardened for Stealth.

Production-grade intelligence pipeline with anti-detection at its core.

⚡
Real-Time Scraping
GraphQL-based X/Twitter scraping with curl_cffi TLS fingerprinting. Human-like delays, session health checks, and automatic cursor resumption.
📊
Economic Calendar
Dual-source scraping from Investing.com and ForexFactory. 9 currencies, impact ratings, 15-minute refresh cycle, timezone-normalized.
🛡
Anti-Detection Engine
Chrome 131 JA3/JA4 fingerprinting, lognormal request delays, per-account seeded fingerprints. Zero suspensions track record.
🔌
Public REST API
Zero-auth v1 API with paginated feeds, author analytics, calendar events, and system stats. Ready for custom integrations.
⚡
Live WebSocket Updates
Supabase Realtime integration for instant tweet delivery. Sub-second latency from post publication to your dashboard.
🔒
Smart Deduplication
Two-layer dedup: in-memory fast-path + PostgreSQL UNIQUE constraint safety net. Zero duplicates guaranteed.
📅
Market-Aligned Scheduling
GitHub Actions cron jobs at market open (9AM ET) and close (3:45PM ET). Economic calendar every 15 minutes, 24/7.
💾
Hybrid Database
Supabase PostgreSQL for production with automatic SQLite fallback. Async-native with asyncpg and aiosqlite drivers.
🖨
Data Export
One-click export to JSON or Excel/CSV with UTF-8 BOM. Full dataset streaming with no row limits.

Zero-Auth Public API
